Refactoring Technique

Removing Duplication

Removing Duplication is a foundational set of refactoring techniques designed to consolidate identical or structurally similar code fragments into a single authoritative source. While Duplicated Code identifies the smell, this technique provides the practical mechanics to eliminate it across different structural scopes—within a single class, across sibling subclasses, or between unrelated modules.

Consolidating duplicate logic directly enforces the DRY (Don't Repeat Yourself) principle. By centralizing shared behavior into well-named methods, base classes, or injected services, developers ensure that future updates or bug fixes only need to occur in one place.

Key Takeaways

  • Directly eliminates technical debt caused by copy-pasted or redundant logic.
  • Creates clear abstractions and establishes single authoritative sources of truth.
  • Minimizes maintenance risk by ensuring business rule changes apply universally.
  • Combines structural refactoring patterns like Extract Method, Pull Up Method, and Form Template Method.

When & How to Apply

Apply this technique whenever you spot duplicated logic across functions, classes, or class hierarchies:

  • Extract Method: Move duplicate statements within the same class into a shared private helper method.
  • Pull Up Method: If two subclasses contain identical methods, extract the shared logic into a common parent superclass.
  • Form Template Method: If subclasses execute the same algorithm structure but differ in specific steps, encapsulate the invariant steps in a base template method and delegate variant steps via abstract calls.
  • Extract Class / Service: If unrelated classes share identical behavior, extract the functionality into a dedicated service component and inject it.

Example / Usage

// BEFORE: Sibling classes duplicating the structure of a report generation workflow
public class HtmlReportGenerator
{
    public void GenerateReport()
    {
        Console.WriteLine("<header>Report Header</header>");
        Console.WriteLine("<body>HTML Content</body>"); // Variant step
        Console.WriteLine("<footer>Report Footer</footer>");
    }
}

public class PdfReportGenerator
{
    public void GenerateReport()
    {
        Console.WriteLine("<header>Report Header</header>");
        Console.WriteLine("[PDF Binary Data]"); // Variant step
        Console.WriteLine("<footer>Report Footer</footer>");
    }
}

// AFTER (C#): Consolidated using the Template Method pattern to remove duplication
public abstract class ReportGeneratorBase
{
    // Shared template method enforcing workflow structure
    public void GenerateReport()
    {
        PrintHeader();
        PrintBody(); // Polymorphic variant step
        PrintFooter();
    }

    private void PrintHeader() => Console.WriteLine("<header>Report Header</header>");
    private void PrintFooter() => Console.WriteLine("<footer>Report Footer</footer>");

    protected abstract void PrintBody();
}

public class HtmlReportGeneratorRefactored : ReportGeneratorBase
{
    protected override void PrintBody() => Console.WriteLine("<body>HTML Content</body>");
}

public class PdfReportGeneratorRefactored : ReportGeneratorBase
{
    protected override void PrintBody() => Console.WriteLine("[PDF Binary Data]");
}
