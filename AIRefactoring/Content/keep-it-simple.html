Refactoring Principle

Keep It Simple (KISS)

The Keep It Simple (KISS) principle asserts that most systems work best if they are kept simple rather than made complicated. Simplicity should be a key goal in design, and unnecessary complexity should be avoided at all costs. Over-engineering code by anticipating speculative future requirements often leads to bloated, hard-to-maintain codebases.

In software refactoring, KISS reminds developers that the cleverest or most abstract solution is rarely the best one. Striving for clear, straightforward C# code ensures that future maintainers can understand and modify the logic without needing to mentally execute intricate design patterns.

Key Takeaways

  • Prioritizes clear, readable C# logic over overly complex or clever implementations.
  • Reduces cognitive load for team members reading, debugging, or extending code.
  • Prevents premature abstraction and over-engineering (YAGNI - You Aren't Gonna Need It).
  • Lowers bug frequency by minimizing intricate conditional branches and layer abstractions.

When & How to Apply

Apply KISS when you encounter code that uses excessive design patterns, deep inheritance trees, or overly complex algorithms for basic tasks. Refactor by flattening unnecessary abstraction layers, replacing complex bitwise or custom evaluation tricks with built-in C# methods, and breaking down monolithic methods into simple, readable steps.

Example / Usage

// BEFORE: Over-engineered evaluation with nested ternary operators and unnecessary abstraction
public class SimpleDiscountEvaluator
{
    public decimal CalculateDiscount(decimal price, bool isMember, bool isHoliday)
    {
        return price > 100 
            ? (isMember ? (isHoliday ? price * 0.30m : price * 0.20m) : (isHoliday ? price * 0.15m : price * 0.10m)) 
            : (isMember ? (isHoliday ? price * 0.15m : price * 0.05m) : 0m);
    }
}

// AFTER: Clean, readable, and straightforward logic using modern pattern matching
public class DiscountCalculator
{
    public decimal CalculateDiscount(decimal price, bool isMember, bool isHoliday)
    {
        if (price <= 0) return 0m;

        decimal discountRate = (price > 100, isMember, isHoliday) switch
        {
            (true, true, true)   => 0.30m,
            (true, true, false)  => 0.20m,
            (true, false, true)  => 0.15m,
            (true, false, false) => 0.10m,
            (false, true, true)  => 0.15m,
            (false, true, false) => 0.05m,
            _                    => 0.00m
        };

        return price * discountRate;
    }
}
