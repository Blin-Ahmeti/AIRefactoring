Code Smell

Duplicated Code

Duplicated Code is widely considered the top code smell in software development. It occurs when two or more code fragments are identical or structurally similar. Whether caused by copy-pasting existing logic or multiple developers independently implementing the same behavior, code duplication inflates the codebase and leads to maintenance headaches.

The primary danger of duplication is inconsistent modification: when a bug is found or a business rule changes, developers must update every duplicate fragment. If even one location is missed, the system falls into an inconsistent state, leading to hard-to-track regressions.

Key Takeaways

  • Significantly increases code maintenance overhead and review effort.
  • Creates high risk of bug propagation when updates are applied incompletely.
  • Often indicates missing abstractions, bad class hierarchy designs, or lack of team communication.
  • Resolved primarily by centralizing identical logic using core refactoring techniques.

When & How to Refactor

Refactor duplicated code whenever you spot identical or similar statements in two or more places:

  • Same class: Use Extract Method and call the new method from both locations.
  • Sibling subclasses: Use Extract Method followed by Pull Up Method to move shared logic into the common superclass.
  • Unrelated classes: Use Extract Class or Extract Component to encapsulate the shared responsibility in a standalone service.

Example / Usage

// BEFORE: Duplicated shipping cost calculations across two distinct services
public class DomesticOrderProcessor
{
    public decimal ProcessOrder(decimal itemTotal, decimal weight)
    {
        // Duplicated shipping calculation logic
        decimal baseShipping = 5.00m;
        decimal weightFee = weight * 1.50m;
        decimal shippingCost = baseShipping + weightFee;

        return itemTotal + shippingCost;
    }
}

public class InternationalOrderProcessor
{
    public decimal ProcessOrder(decimal itemTotal, decimal weight, decimal customsFee)
    {
        // Duplicated shipping calculation logic
        decimal baseShipping = 5.00m;
        decimal weightFee = weight * 1.50m;
        decimal shippingCost = baseShipping + weightFee;

        return itemTotal + shippingCost + customsFee;
    }
}

// AFTER (C#): Extracted shared calculation into a reusable calculator component
public static class ShippingCalculator
{
    public static decimal CalculateStandardShipping(decimal weight)
    {
        const decimal baseShipping = 5.00m;
        const decimal weightRate = 1.50m;
        return baseShipping + (weight * weightRate);
    }
}

public class DomesticOrderProcessor
{
    public decimal ProcessOrder(decimal itemTotal, decimal weight)
    {
        return itemTotal + ShippingCalculator.CalculateStandardShipping(weight);
    }
}

public class InternationalOrderProcessor
{
    public decimal ProcessOrder(decimal itemTotal, decimal weight, decimal customsFee)
    {
        return itemTotal + ShippingCalculator.CalculateStandardShipping(weight) + customsFee;
    }
}
